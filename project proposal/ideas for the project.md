## 1. Зеркальний ATS-асистент (рекрутинг)

 **Суть:** Двосторонній асистент, який аналізує резюме з двох боків — для HR (пошук і ранжування кандидатів) та для кандидата (перевірка власного резюме на «прохідність» ATS-фільтрів, підгонка під вакансію, аналіз прогалин у навичках).

**Як працює:**
* **HR Mode:** завантажує вакансію + пачку резюме $\rightarrow$ отримує ранжований список з % відповідності, «червоними прапорцями» та згенерованими питаннями для інтерв'ю.
* **Candidate Mode:** завантажує своє резюме + текст вакансії $\rightarrow$ отримує ATS-оцінку, рекомендації щодо переформулювання досвіду та план підтягування навичок.

 **Стек:**

| Компонент | Інструмент |
| :--- | :--- |
| **UI** | Streamlit (дві вкладки: HR / Candidate) |
| **Парсинг PDF/DOCX** | `pdfplumber`, `python-docx` |
| **Базовий скоринг** | `scikit-learn` (TF-IDF + косинусна схожість) |
| **Семантичне порівняння** | `sentence-transformers` (`all-MiniLM-L6-v2`, локально на CPU) |
| **LLM для порад** | Google Gemini API (`Flash`, безкоштовний ліміт ~1500 запитів/день) |
| **Секрети** | `python-dotenv` (ключ у `.env`, додати в `.gitignore`) |

## 2. Аналізатор постави при роботі за комп'ютером

**Суть:** Вебкамера в реальному часі відстежує ключові точки тіла. Якщо користувач довго сутулиться або нахиляється до екрана — звучить попереджувальний сигнал.

**Як працює:**
1. `MediaPipe Pose` знаходить 33 ключові точки (ніс, вуха, плечі).
2. `NumPy` обчислює кути нахилу шиї та лінії плечей.
3. Порівняння з калібрувальним (ідеальним) положенням користувача.
4. Якщо відхилення перевищує поріг > 30 секунд $\rightarrow$ сигнал (`winsound` / `pygame.mixer`).

 **Стек:** `opencv-python`, `mediapipe`, `numpy`, `streamlit` або `customtkinter`, `winsound`.

 **Складність:** Легка / Середня.

## 3. Розпізнавання автомобільних номерів з логуванням

 **Суть:** Камера фіксує авто, ШІ зчитує номерний знак та записує час в'їзду/виїзду в базу — прототип «розумного шлагбауму».

 **Як працює:**
1. `OpenCV` захоплює кадр і знаходить контури номерного знака (пороги за кольором/формою).
2. `EasyOCR` (простіший за Tesseract для автономерів) розпізнає текст.
3. Регулярний вираз валідує формат номера (наприклад, `AA1234BB`).
4. Запис у `SQLite`: номер, напрямок, timestamp, фото.

 **Стек:** `opencv-python`, `easyocr`, `sqlite3`, `streamlit` для перегляду журналу.

 **Складність:** Середня.

## 4. Розумний трекер харчування за фото

**Суть:** Користувач завантажує фото страви — нейромережа розпізнає страву та повертає калорії, білки, жири, вуглеводи (БЖУ).

**Як працює:**
1. Фото надсилається в Google Gemini Vision API з промптом: *«Розпізнай страву на фото. Поверни JSON: назва, інгредієнти з приблизною вагою (г), калорії, білки, жири, вуглеводи»*.
2. Python парсить JSON $\rightarrow$ будує гарну статистику.
3. *Опційно:* зберігає історію прийомів їжі в `SQLite` + денний підсумок.

 **Стек:** `google-generativeai`, `streamlit`, `Pillow`, `sqlite3`.

 **Складність:** Середня (завдяки API — без навчання власної моделі).

## 5. Саммаризатор контенту (YouTube / статті)

 **Суть:** Вставляєте посилання — отримуєте короткий список головних тез за пару секунд.

 **Як працює:**
* **YouTube:** `youtube-transcript-api` витягує субтитри $\rightarrow$ текст $\rightarrow$ Gemini API (або локальна модель `facebook/bart-large-cnn` з Hugging Face) $\rightarrow$ список тез.
* **Стаття:** `requests` + `BeautifulSoup` витягують основний текст $\rightarrow$ та ж LLM $\rightarrow$ саммарі.

 **Стек:** `youtube-transcript-api`, `beautifulsoup4`, `requests`, `google-generativeai` (або `transformers` + `torch`).

 **Складність:** Легка / Середня.

## 6. Персональний ШІ-тренер з вимови

 **Суть:** Користувач вимовляє фразу в мікрофон — програма порівнює з еталоном, вказує на помилки та озвучує правильний варіант.

 **Як працює:**
1. `SpeechRecognition` (Google Speech API — безкоштовний) $\rightarrow$ текст із голосу.
2. `difflib.SequenceMatcher` порівнює з еталонною фразою $\rightarrow$ показує відмінності (які слова вимовлено неправильно).
3. `gTTS` озвучує правильний варіант для прослуховування.

 **Стек:** `SpeechRecognition`, `pyaudio`, `gTTS`, `difflib`, `streamlit`.

 **Складність:** Легка.

---

## 7. Генератор палітр за фото (K-Means)

 **Суть:** Завантажуєте фото (інтер'єр, одяг, картина) — отримуєте гармонійну палітру з HEX-кодами.

 **Як працює:**
1. `Pillow` завантажує зображення, конвертує в масив пікселів.
2. `sklearn.cluster.KMeans(n_clusters=5)` знаходить домінуючі кольори.
3. Вивід: 5 кружечків із HEX-кодами + можливість скопіювати.

 **Стек:** `Pillow`, `scikit-learn`, `numpy`, `streamlit`.

 **Складність:** Дуже легка.

## 8. Оцифровка чеків АЗС / СТО (OCR)

 **Суть:** Фотографуєте чек із заправки або автосервісу — програма сама витягує суму, дату, тип витрат і записує в Excel-таблицю бюджету авто.

 **Як працює:**
1. `Tesseract OCR` (або `EasyOCR`) розпізнає текст із фото чека.
2. Регулярні вирази + `spaCy` шукають ключові слова: «Бензин», «Сума», «Дата», «Масло».
3. Автоматичний запис у `SQLite` + експорт у `pandas` $\rightarrow$ Excel/CSV.

 **Стек:** `pytesseract` (або `easyocr`), `Pillow`, `pandas`, `spaCy`, `sqlite3`, `streamlit`.

 **Складність:** Середня (залежить від якості фото чека).
