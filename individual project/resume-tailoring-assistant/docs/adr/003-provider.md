# ADR-003: Провайдер і модель

**Контекст:** основний AI-компонент — Gemini Flash. Але ПР14 вимагає працювати без ключа й без витрат. Крім того, в паспорті є умова перегляду: локальна Qwen, якщо якість < 70 % або Gemini free tier скорочено.

**Рішення:**
- Абстракція `Provider` з контрактом: `ProviderRequest → ProviderResult | ProviderError`.
- Три реалізації: `mock` (ПР14), `openai_compat` (ПР15, Gemini через OpenAI-сумісний endpoint), `local` (заготовка ПР15+, Qwen через vLLM або llama.cpp).
- Вибір — змінна `LLM_PROVIDER` у `.env`. Одна змінна, без зміни коду.

**Наслідки:**
- (+) Тести завжди на `mock`, платний API не викликається.
- (+) Заміна Gemini → Qwen не торкається сервісу чи оркестрації.
- (−) `openai_compat` у ПР14 — заготовка з контрольованою помилкою «не реалізовано»; це свідомо, бо ПР15 додає реальний код.
