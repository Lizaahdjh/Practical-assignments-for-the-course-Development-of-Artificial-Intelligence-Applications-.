# ADR-002: Сховище

**Контекст:** потрібно зберігати історію запитів (для журналу, оцінювання, дебагу) і фідбек користувача. Один користувач, демонстрація, розгортання на Streamlit Cloud.

**Рішення:** SQLite (`data/app.db`) через стандартний `sqlite3` + модульний інтерфейс `storage.py`.

**Наслідки:**
- (+) Нуль конфігурації, файл, що легко видалити.
- (+) Модульний інтерфейс (`save_request`, `get_request`, `save_feedback`) дозволяє замінити на in-memory у тестах.
- (−) Не підходить для паралельних записів з кількох воркерів — але в ПР14–ПР20 у нас один процес uvicorn.
- (−) Схема створюється кодом при старті (`CREATE TABLE IF NOT EXISTS`) — цього достатньо для проєкту.
