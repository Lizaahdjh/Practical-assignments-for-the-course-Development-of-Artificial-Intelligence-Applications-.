# ПР2. Локальний inference спеціалізованої моделі

Веб-застосунок для локального розпізнавання об'єктів на зображеннях із використанням готової pretrained-моделі **YOLOv8n**.

Застосунок приймає зображення від користувача, виконує локальний inference без звернення до зовнішніх API та відображає знайдені об'єкти. Для кожного об'єкта показуються його клас, координати bounding box та рівень упевненості (`confidence`). Також відображаються загальна кількість знайдених об'єктів і час виконання inference.

Бекенд реалізовано за допомогою **FastAPI**, а роботу з моделлю винесено в окремий модуль `app/detector.py`.

Інтерфейс підтримує дві мови — **українську та British English** — та містить стилізований елемент завантаження файлів і інтерактивний **HTML5 Canvas** для візуалізації результатів розпізнавання.

---

## Задача

Основна мета практичної роботи — створити веб-застосунок із локальним використанням спеціалізованої моделі комп'ютерного зору.

Застосунок повинен:

* приймати зображення від користувача;
* виконувати локальний inference за допомогою YOLOv8n;
* знаходити об'єкти на зображенні;
* визначати клас кожного об'єкта;
* визначати координати bounding box;
* визначати рівень упевненості моделі;
* показувати кількість знайдених об'єктів;
* вимірювати час виконання inference;
* дозволяти змінювати Confidence Threshold;
* візуалізувати результати на зображенні;
* обробляти помилки некоректного файлу або inference;
* працювати без звернення до зовнішніх API під час розпізнавання.

# Локальний inference

Основною особливістю проєкту є виконання inference **локально**.

Для розпізнавання використовується готова pretrained-модель:

```text
yolov8n.pt
```

Модель не звертається до зовнішнього API під час обробки зображення.

Загальна схема роботи:

```text
Зображення користувача
        ↓
FastAPI
        ↓
Валідація зображення
        ↓
YOLOv8n
        ↓
Локальний inference
        ↓
Результати розпізнавання
        ↓
JSON-відповідь
        ↓
HTML5 Canvas
        ↓
Відображення bounding boxes
```

---

# Завантаження моделі

Ваги `yolov8n.pt` завантажуються в пам'ять **один раз під час запуску FastAPI**.

Для цього використовується `lifespan` контекст.

Такий підхід дозволяє:

* уникнути повторного завантаження моделі;
* не створювати модель при кожному HTTP-запиті;
* зменшити затримку обробки;
* ефективніше використовувати ресурси системи.

---

# Модуль `app/detector.py`

Уся логіка роботи з YOLOv8 винесена в окремий модуль:

```text
app/detector.py
```

Модуль відповідає за:

* завантаження моделі;

* отримання результатів;
* визначення класів об'єктів;

* визначення `confidence`;
* вимірювання часу виконання;
* обробку помилок inference.

Веб-рівень `app/main.py` не містить безпосередньої логіки роботи з моделлю.

# Результат розпізнавання

Для кожного знайденого об'єкта формується структурований результат.

Він містить:

* **class** — клас об'єкта;
* **xmin** — ліва координата рамки;
* **ymin** — верхня координата рамки;
* **xmax** — права координата рамки;
* **ymax** — нижня координата рамки;
* **confidence** — рівень упевненості моделі.

Приклад структури:

```json
{
  "class": "person",
  "xmin": 120,
  "ymin": 80,
  "xmax": 350,
  "ymax": 520,
  "confidence": 0.91
}
```

Також результат містить загальну кількість знайдених об'єктів та час виконання inference.

---

# Confidence Threshold

Користувач може регулювати **Confidence Threshold**.

Значення порогу знаходиться в діапазоні:

```text
0.0 – 1.0
```

Чим вище значення порогу, тим суворішими є вимоги до впевненості моделі.

Наприклад:

```text
0.25
0.50
0.75
```

Об'єкти з рівнем упевненості нижче встановленого порогу не відображаються серед результатів.

# HTML5 Canvas

Для візуалізації результатів використовується **HTML5 Canvas**.

Після виконання inference:

1. отримується оригінальне зображення;
2. отримуються координати bounding boxes;
3. визначається масштаб відображення;
4. на Canvas малюються рамки;
5. біля рамок відображаються назви класів;
6. показується рівень упевненості.

Схематично:

```text

│       ┌──────────────┐            │
│       │    person    │            │
│       │   0.91       │            │
│       │              │            │
│       │              │            │
│       └──────────────┘            │
│                                   │
│              ┌───────────┐        │
│              │   car     │        │
│              │   0.87    │        │
```

# Метрики оцінювання

### Precision

Показує, яка частина знайдених моделлю об'єктів є правильними.

```text
Precision = TP / (TP + FP)
```

де:

* `TP` — правильно знайдені об'єкти;
* `FP` — помилково знайдені об'єкти.

### Recall

Показує, яку частину реальних об'єктів модель змогла знайти.

```text
Recall = TP / (TP + FN)
```

де:

* `TP` — правильно знайдені об'єкти;
* `FN` — пропущені об'єкти.

### Середній час inference

Визначає середній час, необхідний моделі для обробки одного зображення.

# Висновок

У результаті виконання практичної роботи було створено веб-застосунок для локального розпізнавання об'єктів на зображеннях за допомогою pretrained-моделі **YOLOv8n**.

Застосунок реалізовано на **FastAPI**, а логіку роботи з моделлю винесено в окремий модуль `app/detector.py`. Ваги моделі завантажуються один раз під час запуску сервера, після чого inference виконується локально без використання зовнішніх API.

Для кожного знайденого об'єкта визначаються його клас, координати bounding box та рівень упевненості. Результати візуалізуються за допомогою **HTML5 Canvas**. Також реалізовано регулювання Confidence Threshold, підрахунок кількості об'єктів та вимірювання часу виконання inference.

Веб-інтерфейс підтримує **українську та British English** мови, має стилізований елемент завантаження зображень та адаптивний дизайн. Для підвищення надійності застосунку реалізовано Rate Limiting, валідацію вхідних даних та спеціалізовану обробку помилок.

Для перевірки якості передбачено окремий модуль `eval`, який дозволяє автоматично розрахувати **Precision**, **Recall** та середній час inference.
